# Pantry website

For local use, copy `.env.example` to `.env` and leave `VITE_API_BASE_URL` empty. The local Vite server forwards API requests to port `5050`.

For deployment, set `VITE_API_BASE_URL` to the public API address before building the website. See the main [product overview](../README.md) and [API deployment guide](../server/README.md).
